# Royal Wellness CRM — Frontend Application

Modern, real-time WhatsApp Concierge & Clinical Lead Management Dashboard built with **React 19**, **TypeScript**, **TailwindCSS**, **Recharts**, and **Lucide Icons**.

## Features
- **WhatsApp Web Live Thread**: Native chat UI with multi-reaction picker, reply preview, message info, message pinning, and template drawer.
- **Multilingual Support**: English, Sinhala (සිංහල), and Tamil (தமிழ்) translation previews.
- **CRM Intelligence Workspace**: Patient profile card, verified WhatsApp phone numbers, treatment history, and conversion timeline.
- **Lead Pipeline**: Kanban and Table views with SLA monitoring and coordinator workload distribution.
- **Real-Time Gateway Sync**: Listens to backend Server-Sent Events (SSE) on `http://localhost:3001/api/events`.

## Quick Start

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev
# Running on http://localhost:5173
```
