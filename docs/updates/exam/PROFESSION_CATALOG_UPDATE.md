# Profession Exam Catalogue Update

Updated the active CRM catalogue with the 90 requested healthcare professions.

- 90 new, stable course records were added under `created_by = profession-catalog-import`.
- Every new record is `Draft` and `Assigned Students Only` so no unreviewed course is publicly available.
- Every record has a relevant existing Alpha Health Group category cover: medical, dental, nursing, pharmacy, rehabilitation, occupational therapy, or laboratory.
- Existing seven courses were preserved. The database now contains 97 total exam courses.
- The course directory already supports search by profession/title/code and authority filtering.
- The course manager master list now displays all 90 profession titles.

Before activating any draft course, confirm its licensing authority, country, syllabus, exam blueprint, reviewed study materials, and question bank. Official regulator logos should only be added when supplied or licensed; the current covers use the Alpha Health Group brand mark plus category artwork.
