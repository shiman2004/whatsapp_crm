# Exam Handoff Notifications & Automatic Timestamps

Implemented in the local CRM on 28 October 2026.

## Workflow

1. Sales forwards a lead to **Exam Department**.
2. The Head of Exam sees a durable inbox item and an in-app/desktop notification.
3. The Head accepts the handoff, assigns an exam providing officer, and the assignment time is saved.
4. The assigned officer receives an assignment notification and can select **Accept requirement**.
5. The officer can select **Start work** and then **Complete handoff** after delivery to the CRM.
6. The Head receives a notification when the officer accepts the requirement.

## Automatic date/time fields

The inbox shows the browser's local date and time for:

- Forwarded
- HOE accepted
- Assigned
- Officer accepted
- Started
- Completed

The timestamps are generated by the server during each audited status change; the UI formats them for the user's local timezone.
