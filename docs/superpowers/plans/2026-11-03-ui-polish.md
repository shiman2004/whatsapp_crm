# UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the shared non-login interaction defects found in the frontend audit.

**Architecture:** Tailwind owns global hover generation; shared UI primitives own repeatable button and overlay behavior; global CSS owns the legacy context menu. No feature routes or authentication behavior change.

**Tech Stack:** React, TypeScript, Tailwind CSS 3, Vite.

**Spec:** `docs/superpowers/specs/2026-11-03-ui-polish-design.md`

## Global Constraints

- Do not modify pre-login staff selectors, authentication, APIs, roles, or backend code.
- Preserve the existing design tokens and component contracts.
- Do not add dependencies.

## Review Focus

- Touch devices must not retain hover-only feedback after a tap.
- Disabled shared buttons must not scale when pressed.
- Drawer and dialog body scrolling must not propagate to the page behind.
- Existing focus, dark-mode, and click behavior must remain intact.
